## 1. What this app does
It's for people who are going online grocery shopping. The primary resource of this project is inventory management.

## 2. How to run it
Need node version 22.22.1 or higher. Server and client need npm install. To start off with this project, make a new folder, name it whatever you like, and do a git clone (repo url). The repo was last tested from a fresh clone on 11/12/26 by Emma.
